# FMI Workspace

Central repository for my university coursework at FMI. It keeps the material for every subject in one place and is used to coordinate group and individual projects through git.

## Layout

Each subject is a subdirectory of `projects/`:

```
projects/
├── architecture-of-software-systems/
└── object-oriented-analysis-and-design-of-software-systems/
```

A subject folder holds its lecture notes (`lecture_notes.md`), assignment material and project artifacts such as diagrams.
